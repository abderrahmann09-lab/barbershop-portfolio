## 🚀 Come Usare

### Opzione 1: GitHub Pages (Automatico)
1. Il repository è già configurato per GitHub Pages
2. Vai a **Settings** → **Pages**
3. Seleziona **main branch**
4. Il sito sarà disponibile a: `https://abderrahmann09-lab.github.io/barbershop-portfolio/`

### Opzione 2: Locale
```bash
# Clona il repository
git clone https://github.com/abderrahmann09-lab/barbershop-portfolio.git

# Apri il file index.html nel browser
open index.html
```

## 🎨 Personalizzazione

### Cambiare Colori
Modifica le variabili CSS in `style.css`:
```css
:root {
    --primary-color: #1a1a1a;      /* Nero */
    --secondary-color: #d4af37;    /* Oro */
    --accent-color: #2d2d2d;       /* Grigio scuro */
}
```

### Aggiungere Immagini Galleria
Sostituisci i placeholder nella sezione Gallery con vere immagini:
```html
<div class="gallery-placeholder">
    <img src="path/to/image.jpg" alt="Descrizione">
</div>
```

### Modificare Info Contatti
Aggiorna i dati nel section Contact:
- Indirizzo
- Telefono
- Email
- Orari

### Personalizzare Prezzi
Modifica le card nella sezione Prices con i tuoi prezzi reali.
